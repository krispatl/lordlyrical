# Original Blender authoring sources

These files were collected from the original Lord Lyrical asset workspace on 2026-10-10. They include the chamber, original cybernetic dragon, JERU working and distance rigs, ten individual participant avatars and their combined workshop, Sonic Orc, retargeting workshop and performance props.

Unity uses the checked-in exports under `Assets/`; Blender files remain outside `Assets/` to avoid automatic Blender imports. Preserve the existing rigs and dragon. Some historical authoring scripts/Blender image references use original workstation paths and may need relinking. Inspect paths before running generation scripts; do not treat them as a portable build pipeline. Unity's exported model/texture assets are the current runtime source of truth.

`.blend1` automatic backups and duplicate Unity packages are not included. Large originals are stored with Git LFS. Third-party assets and likeness/reference imagery retain their original ownership and licenses.
